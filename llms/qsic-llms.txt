## Important for agents

Qsic publishes **no public API**. As of 2026-08-26 there is no developer portal, no API reference,
no OpenAPI/AsyncAPI/GraphQL/Protobuf/WSDL contract, no SDK in any public package registry, no MCP
server and no A2A agent card. `https://www.getqsic.com/developers`, `/docs` and `/api` all return
HTTP 404, and no docs or developer subdomain resolves. A live JSON API host exists at
`https://api.getqsic.com` — it returns `{"status":"ok"}` at `/health` and a structured error
envelope `{"error":{"code":...,"message":...,"request_id":...}}` elsewhere — but it is the product's
own backend, undocumented and unadvertised. Do not attempt to integrate with it; contact Qsic
instead.
